LLM : llm is basically the Large Language Models, basically it's a advanced form of AI that is used to generate logical human readable real world respose for the queries given by the users.

Tokens : the process of breaking down the text into smaller chunks is called tokenization and the each smaller chunk is called tokens.

Prompts : There are two types of prompts one is system prompt and another is user prompt, the system prompt is which is hardcoded and the llm uses this as an advisor prompt that tells how to provide output and what format and all . User prompt is the prompt given by user which comes on top of these whatever user wants to ask to llm and expect the response based on it.
