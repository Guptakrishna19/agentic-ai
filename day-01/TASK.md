Complete these in order. Do not skip ahead — each step builds on the previous one.

### Step 2
Install Python 3.11+. Create a virtual environment: `python -m venv venv` and activate it

### Step 3
Install Git. Configure your name and email: `git config --global user.name` and `user.email`

### Step 4
Create a folder `hello-internship`. Write `hello.py` that prints your name and today's date

### Step 5
Initialize Git: `git init`, `git add .`, `git commit -m "Day 1 setup"`
