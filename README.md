# Dhruv Lukhi — 2-Month Training Plan

**Starting Level:** Beginner (assumes basic programming exposure)  
**End Goal:** Build and deploy a production-ready AI application with RAG and multi-agent workflows

## How This Plan Works

- Every day has a **Learn First** section — study these topics before touching code
- Tasks are **step-by-step** and get harder gradually across 8 weeks
- You go from **zero setup** on Day 1 to a **deployed capstone** on Day 40
- If stuck, ask your mentor — don't skip the Learn First section

## Curriculum Overview

| Week | Theme | Level | What You'll Learn |
|------|-------|-------|-------------------|
| 1 | Python & Dev Environment | Beginner | Setup, Python basics, OOP, CLI project |
| 2 | Data Structures, SQL & Databases | Beginner | Arrays, sorting, SQL, Python + DB app |
| 3 | Web APIs & Full-Stack Basics | Beginner → Intermediate | HTTP, FastAPI, frontend, full-stack app |
| 4 | AI, LLMs & LangChain | Beginner → Intermediate | LLMs, prompts, LangChain, simple agents |
| 5 | RAG Systems | Intermediate | Embeddings, vector stores, document Q&A |
| 6 | LangGraph, CrewAI & Multi-Agent | Intermediate | Agent workflows, research crews |
| 7 | System Design, Docker & Cloud | Intermediate | Scaling, caching, deployment |
| 8 | Capstone Project | Advanced | End-to-end AI app, demo, retrospective |

## Week-by-Week Milestones

| Week | Milestone Project |
|------|-------------------|
| 1 | CLI Task Manager (Python + OOP) |
| 2 | Employee Management (Python + SQLite) |
| 3 | Full-Stack Employee App (FastAPI + HTML/JS) |
| 4 | AI-Powered CLI Assistant (LangChain agent) |
| 5 | Document Q&A Web App (RAG pipeline) |
| 6 | Multi-Agent Research Assistant (LangGraph/CrewAI) |
| 7 | Deployed RAG App on Cloud (Docker + Redis) |
| 8 | **Capstone:** Production AI Research Assistant |

## Capstone (Days 36–40)

Build, deploy, and present an **AI Research Assistant** that:
- Accepts document uploads and answers questions (RAG)
- Uses multi-agent workflow for report generation
- Runs on cloud with proper documentation
- Includes a 10-minute demo to the team

## Daily Workflow

1. Open `day-XX/TASK.md`
2. Complete **Learn First** → write `learn-first-notes.md`
3. Finish all task steps in order
4. Submit deliverables in the day folder
5. Write `reflection.md` (3 learnings + 1 doubt)
6. Check off the completion checklist
