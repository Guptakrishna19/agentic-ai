An AI Agent is a Large Language Model (LLM) that can:

1. Think about a problem
2. Choose a tool
3. Use the tool
4. Observe the result
5. Decide the next step
6. Return a final answer
7. Use multiple tools to answer questions
8. can perform a task like bookin tickets or ordering food

AI Agent = LLM + Tools + Decision Loop

## What is a Tool?
A tool is a function that an agent can call to perform actions.
